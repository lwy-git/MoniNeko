# Phase 1-H：语音记账

## Context

在现有手动记账和快捷模板基础上，增加自然语言语音录入能力。用户说出“早餐花了 8 块”或“工资到账 8000 元”等口语内容后，系统自动识别文字并解析收支类型、金额、分类和备注，最终回填到原有记账表单，由用户确认后保存。

## 完成内容

### Step 1：跨平台语音识别

**文件**：`hooks/use-voice-recognition.js`、`manifest.json`

- App 端通过 HTML5+ Speech 模块调用系统语音识别能力
- Android 增加录音权限申请和 `RECORD_AUDIO` 权限声明
- iOS 增加麦克风及语音识别用途说明
- H5 端优先使用浏览器 Web Speech API
- 小程序等未接入平台会提示当前平台暂不支持
- 单次识别最长 15 秒，支持主动取消和超时反馈
- 识别失败、无语音、权限被拒绝和网络异常均提供用户提示

### Step 2：自然语言结构化解析

**文件**：`utils/voice-expense-parser.js`

- 识别阿拉伯数字和常用中文数字金额
- 支持“十二块五”“六十八块五毛”“一百二十元”等口语金额
- 根据“工资、到账、红包、兼职”等关键词判断收入
- 根据餐饮、交通、购物、娱乐、医疗、住房、猫咪等关键词匹配分类
- 清理金额和记账指令后生成简洁备注
- 金额缺失时保留其他识别结果，并提示用户手动补充

### Step 3：记账页交互

**文件**：`pages/add/index.vue`

- 新增语音记账入口和示例文案
- 录音时显示遮罩、波形动画和取消按钮
- 识别完成后展示原始文本、收支类型、分类和金额
- 自动回填金额、分类、备注及收入/支出切换
- 识别结果不会直接保存，用户可继续修改并点击完成
- 离开页面时自动终止仍在进行的语音识别

## 示例

| 语音内容 | 解析结果 |
| --- | --- |
| 早餐花了 8 块 | 支出 / 餐饮 / 8 元 / 早餐 |
| 打车二十五元 | 支出 / 交通 / 25 元 / 打车 |
| 买猫粮花了六十八块五毛 | 支出 / 猫咪 / 68.5 元 / 买猫粮 |
| 工资到账 8000 元 | 收入 / 工资 / 8000 元 / 工资 |
| 收到红包二百元 | 收入 / 红包 / 200 元 / 红包 |

## 验证清单

1. App 首次使用时正确申请麦克风权限
2. 点击语音记账后显示监听动画，取消按钮可终止识别
3. 支出语音可正确回填金额、分类和备注
4. 收入语音可自动切换收入类型并匹配收入分类
5. 中文数字、阿拉伯数字和常用口语小数均可解析
6. 未说金额时不会误保存，并提示手动补充金额
7. 识别结果回填后仍可手动修改所有字段
8. 识别结果需用户点击完成才会写入账目
9. 不支持的平台提供明确提示，不影响手动记账
10. 离开记账页时不会残留录音或监听状态
