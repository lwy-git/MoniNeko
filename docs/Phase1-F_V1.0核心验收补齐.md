# Phase 1-F: V1.0 核心验收补齐

## Context

Phase 1-A 至 Phase 1-E 已完成基础架构、核心记账、交互优化、数据功能和猫咪养成。本阶段依据 PRD 的 V1.0 验收标准反查核心路径，优先补齐仍未接通的日期明细和快捷模板能力。

## 完成内容

### Step 1: 日历日期进入当日明细

**文件**: `pages/home/index.vue`、`pages/detail/index.vue`、`store/expense-store.js`

- 点击首页日历中的有效日期，进入对应日期的收支明细
- 当日明细展示该日记录和净支出汇总
- 当日明细提供“快速记一笔”入口
- 历史日期快速记账时，记录写入所选日期而非固定写入今天
- 历史日期快速记账保存后返回该日明细，保持操作上下文
- 离开明细页后清理日期上下文，普通明细入口仍展示本月记录
- 首页日历金额仅聚合支出，不把收入计入消费金额

### Step 2: 快捷记账模板

**文件**: `pages/add/index.vue`、`store/expense-store.js`

- 接通已有 `expense_record.is_template` 和 `loadTemplates` 数据能力
- 支持将当前类型、分类、金额和备注保存为快捷模板
- 点击模板自动填充记账表单
- 长按模板可确认删除
- 重复模板会提示，不重复写入
- 模板记录不会混入首页、明细和统计数据

### Step 3: 编辑返回上下文

**文件**: `pages/add/index.vue`

- 从明细编辑记录并保存后，返回该记录所属日期的明细
- 收入/支出类型切换同步重置分类，模板填充和编辑回显不会被异步监听覆盖

## 验证清单

1. 首页点击任意当月日期，明细页只显示该日记录
2. 历史日期点击“快速记一笔”，保存后记录日期与所选日期一致
3. 从 TabBar 直接进入明细页，仍显示当前月全部记录
4. 收入不会累计到首页日历的每日消费金额
5. 填写金额和备注后保存模板，重新进入记账页仍可加载
6. 点击支出或收入模板，类型、分类、金额和备注正确回填
7. 长按模板确认删除后，模板列表立即更新
8. 模板数据不出现在明细、统计或猫咪连续记账计算中
