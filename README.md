# 招财记账（MoniNeko）

一款以猫咪陪伴和养成为主题的本地优先个人记账应用。MoniNeko 将日常收支、月度预算、消费统计和虚拟猫咪成长结合起来，让记账不只是录入数字，也能获得持续、轻量的情感反馈。

项目基于 **uni-app + Vue 3 + Pinia** 开发，当前版本以游客模式和本地数据存储为主，可通过 HBuilderX 运行到 H5、App 和小程序等平台。

## 项目特色

- **快速收支记录**：支持支出与收入分类、金额输入、备注、编辑和删除。
- **快捷记账模板**：可将常用类型、分类、金额和备注保存为模板，一键回填；长按模板可删除。
- **语音记账**：说出“早餐花了 8 块”等自然语言，自动识别收支、金额、分类和备注并回填表单。
- **日历记账视图**：首页按月展示每日支出，点击日期即可查看当天明细并补记历史账目。
- **明细搜索筛选**：按月份查看记录，支持关键词搜索、分类筛选和左滑删除。
- **月度预算管理**：设置每月预算，实时查看已用、剩余金额和每日建议额度。
- **消费统计与报告**：提供周期统计、分类汇总、趋势信息和每日结算建议。
- **本地数据导出**：支持将账目导出为 CSV，模板数据不会混入业务统计或导出结果。
- **猫咪养成系统**：记账、签到和完成任务可获得小鱼干，推动猫咪升级并解锁成就。
- **猫咪装扮商店**：使用可用小鱼干购买装扮，支持等级解锁、穿戴、卸下和跨页面展示。
- **多品种猫咪形象**：不同猫咪品种使用独立 SVG 资源，并跟随用户选择动态展示。
- **本地优先存储**：App 端使用 SQLite，H5 与小程序端使用本地存储适配器，V1.0 无需登录或联网。

## 当前版本

当前为 **V1.0**，已完成基础架构、核心记账、交互优化、数据功能、猫咪养成，以及日期明细和快捷模板等核心验收能力。

暂未包含：

- 账号注册与登录
- 云端同步和多设备共享
- 桌面小组件

以上能力计划在后续版本逐步完善。

## 核心数据流

```text
页面（pages）
  ↓
Pinia Store（store）
  ↓
业务 Hooks（hooks）
  ↓
数据库适配层（utils/db）
  ↓
SQLite（App）或本地存储（H5 / 小程序）
```

数据库目前包含用户、月度预算、收支记录、猫咪状态、已购装扮和成就六类核心数据。快捷模板复用收支记录结构，并通过 `is_template` 字段与普通账目隔离。

## 本地运行

### 环境要求

- HBuilderX（推荐使用最新稳定版）
- Node.js 与 npm（用于安装项目依赖）
- 如需运行原生 App，请准备对应的 Android 或 iOS 调试环境

### 启动步骤

1. 克隆项目并进入目录：

   ```bash
   git clone <repository-url>
   cd MoniNeko
   ```

2. 安装依赖：

   ```bash
   npm install
   ```

3. 使用 HBuilderX 打开项目。
4. 在 HBuilderX 中选择“运行”，然后选择目标平台进行预览：
   - 运行到浏览器：适合日常 H5 开发调试
   - 运行到 App：使用 SQLite 验证原生端数据持久化
   - 运行到小程序模拟器：验证对应平台的界面与本地存储

> 当前项目未配置完整的命令行运行、自动化测试和 ESLint 脚本，开发与发行以 HBuilderX 为主。

## 开发约定

- 使用 Vue 3 Composition API 和 `<script setup>`。
- 文件及组件目录统一采用 kebab-case 命名。
- 页面负责展示与交互，业务逻辑放入 Hooks，共享状态由 Pinia Store 管理。
- 样式尺寸优先使用 `rpx`，主题颜色和圆角使用全局 CSS 变量。
- 平台差异通过 uni-app 条件编译处理，避免直接操作浏览器 DOM/BOM。
- 提交信息遵循 Conventional Commits，例如：`feat: 新增快捷记账模板`。

更完整的编码要求请查看 [开发规范](./docs/开发规范.md)。
